One line of awkward small talk that one robot says to another while they ride an elevator together. The line is written by `main.py` to `/output/entry.txt` (UTF-8, 1–200 characters, a single line), where the sealed scorer gates it before the judge compares it head to head against the other entries.

## Run it

```sh
python3 main.py
```
